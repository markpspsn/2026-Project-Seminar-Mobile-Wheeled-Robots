# Практическая работа 1 — вариант 10

Пакет `draw_10` запускает две черепахи в `turtlesim`. Первая черепаха рисует цифру 1, вторая — цифру 0.

## Запуск программы

### 1. Запуск Docker-контейнера

Открыть обычный терминал Ubuntu и перейти в корень репозитория:

```bash
cd ~/Projects/mobile-robots-project-seminar
```

Запустить контейнер:

```bash
HOST_XAUTHORITY="$XAUTHORITY" docker compose --env-file .env --env-file .env.local -f docker-compose.yaml -f docker-compose.gpu.yaml up -d
```

### 2. Вход в контейнер

В том же терминале выполнить:

```bash
HOST_XAUTHORITY="$XAUTHORITY" docker compose --env-file .env --env-file .env.local -f docker-compose.yaml -f docker-compose.gpu.yaml exec -it ros2-base zsh
```

После выполнения команды откроется терминал внутри Docker-контейнера.

### 3. Сборка пакета

Внутри контейнера выполнить:

```bash
cd ~/practices_ws
colcon build --symlink-install --packages-select draw_10
source install/setup.zsh
```

### 4. Запуск черепах

Внутри контейнера выполнить:

```bash
ros2 launch draw_10 number.launch.py
```

После запуска откроется окно `turtlesim`. Две черепахи нарисуют число 10.

Терминал с запущенной командой и окно `turtlesim` закрывать пока нельзя. Они должны продолжать работать во время запуска графа узлов.

Для завершения программы нужно нажать `Ctrl+C` в терминале, но делать это следует только после проверки графа узлов.

## Проверка графа узлов

Граф узлов показывает, какие программы ROS 2 сейчас работают и через какие топики они передают данные.

На графе должны присутствовать:

- узел `turtlesim`;
- узел управления первой черепахой;
- узел управления второй черепахой;
- топики `pose`, через которые программа получает положение черепах;
- топики `cmd_vel`, через которые программа отправляет команды движения.

### 1. Открытие второго терминала

Не закрывая первый терминал и окно `turtlesim`, открыть второй обычный терминал Ubuntu.

Во втором терминале перейти в корень репозитория:

```bash
cd ~/Projects/mobile-robots-project-seminar
```

### 2. Вход в тот же контейнер

Во втором терминале выполнить:

```bash
HOST_XAUTHORITY="$XAUTHORITY" docker compose --env-file .env --env-file .env.local -f docker-compose.yaml -f docker-compose.gpu.yaml exec -it ros2-base zsh
```

Важно: следующие команды необходимо выполнять внутри контейнера, а не в обычном терминале Ubuntu.

### 3. Запуск графа

Внутри контейнера выполнить:

```bash
cd ~/practices_ws
source install/setup.zsh
rqt_graph
```

Откроется окно `rqt_graph`.

В верхнем выпадающем списке нужно выбрать:

```text
Nodes/Topics (all)
```

Затем нажать кнопку обновления с круговыми стрелками в левом верхнем углу окна.

Если граф пустой, необходимо проверить, что:

1. первый терминал с командой `ros2 launch draw_10 number.launch.py` всё ещё работает;
2. окно `turtlesim` не было закрыто;
3. в первом терминале нет сообщений `process has died`;
4. в `rqt_graph` выбран режим `Nodes/Topics (all)`;
5. после выбора режима была нажата кнопка обновления.

После проверки графа программу можно остановить сочетанием `Ctrl+C` в первом терминале.
